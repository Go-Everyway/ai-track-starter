# Data dictionary

Everything here is synthetic and generated by `tools/generate_data.py` from a fixed seed. The seller in every dataset is Tallyhawk, a fictional company selling inventory-forecasting software to mid-size distributors and manufacturers.

## leads_clean.csv

One row per lead. 4,000 rows.

| Column | Meaning |
|---|---|
| `lead_id` | Lead identifier. |
| `company_id` | Company identifier; joins to `companies.jsonl`. |
| `company` | Company name (generated). |
| `industry` | One of ten industries. |
| `employees` | Headcount. |
| `country` | United States, Canada, United Kingdom, Germany or Australia. |
| `lead_source` | How the lead arrived: `inbound_demo`, `pricing_page`, `referral`, `webinar`, `content_download`, `event`, `outbound`. |
| `seniority` | `c_level`, `vp`, `director`, `manager`, `individual`. |
| `job_function` | `operations`, `supply_chain`, `finance`, `it`, `sales`, `marketing`. |
| `created_date` | Date the lead was created (2025). |
| `pages_viewed` | Website pages viewed. |
| `pricing_page_visits` | Visits to the pricing page. |
| `email_opens`, `email_clicks` | Marketing email engagement. |
| `webinar_attended` | 1 if they attended a webinar. |
| `erp_type` | The ERP they run: `none`, `legacy`, `cloud`. |
| `hiring_ops_roles` | 1 if the company has open operations roles. |
| `recent_funding` | 1 if the company raised money recently. |
| `meetings_held` | Sales meetings logged against the lead in the CRM. |
| `converted` | 1 if the lead became a customer. The label. |

## leads_messy.csv

The same leads as they'd come out of a real CRM, plus 120 duplicate entries. Expect blanks, the same category spelled several ways, employee counts as text or ranges, three date formats, and a few impossible values. It also has `contact_name` and `contact_email`. They're generated, and the emails use the reserved `.example` domain, but treat them the way you'd treat real personal data.

## companies.jsonl

400 company profiles, one JSON object per line: `company_id`, `name`, `industry`, `employees`, `country`, `is_customer`, `signals` (recent events, such as hiring or a new warehouse) and `description` (a few sentences of plain text).

## docs/ and questions.jsonl

`docs/` holds Tallyhawk's knowledge base: product, pricing, security, support, integrations and fictional case studies. The integrations name products that are also fictional.

`questions.jsonl` has one question per line with `doc_id` and `answer_passage`: the exact sentence in that document that answers it. That's what lets you score retrieval (did the right passage come back?) separately from the answer.
